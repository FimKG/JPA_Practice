# JPA Practice

A Java project showcasing **Java Persistence API (JPA)** fundamentals with practical examples.  
This repository is designed to help developers understand how to map Java objects to relational databases, perform CRUD operations, and explore advanced JPA features.

---

## 📚 Overview
This project demonstrates:
- Setting up JPA with a relational database
- Defining **entities** with annotations (`@Entity`, `@Id`, `@GeneratedValue`)
- Managing relationships (`@OneToOne`, `@OneToMany`, `@ManyToMany`)
- Performing CRUD operations using `EntityManager`
- Querying with **JPQL** and **Criteria API**
- Handling transactions and persistence contexts

---

## 🛠️ Technologies Used
- **Java 17+**
- **Hibernate** (JPA implementation)
- **Maven** for build automation
- **MySQL** configuration
